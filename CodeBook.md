CodeBook
This CodeBook describes the data, variables, and transformations used in the tidy_data.txt file.

Data Source
Wearable computing data from the UCI Machine Learning Repository (Samsung Galaxy S smartphone).

Transformations
Merged training and test sets.
Extracted only mean and standard deviation measurements.
Applied descriptive activity names.
Cleaned variable names to be descriptive.
Created a final summary table grouped by Subject and Activity.
